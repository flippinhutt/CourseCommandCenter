# Requirement - Survey Link Sharing

## Requirement statement

The system shall let a user generate a shareable survey link.

## Functional / non-functional

Functional.

## Acceptance criteria

- [ ] Link is generated without requiring a login
- [ ] Link opens the correct survey form
- [ ] Link works when shared outside the app
